# Two Asset SJM baseline

## Purpose

Baseline two-asset sparse jump-model allocation pipeline.

## Files

* `Two Asset SJM baseline.ipynb`: main notebook.
* `functions.py`: helper functions.
* `data/`: input data used by the notebook.
* `outputs/`: generated outputs.

## How to run

1. Open `Two Asset SJM baseline.ipynb`.
2. Run the notebook from top to bottom.

## Data

The required panel is included in `data/`.

Input file:

* `model_panel_start_1970_01_31.parquet`

## Outputs

Generated outputs are written to `outputs/`.
